# Ranking artwork

Production assets used by the Ranking page:

- `ranking-champion-banners-pixel-v1.webp`: transparent 1080 × 720 artwork containing the ceremonial 2–1–3 banners. Player avatars are rendered behind its transparent portrait openings; names and XP remain dynamic HTML.
- `ranking-controls-emblems-pixel-v1.png`: transparent icon sheet used by the Global, Minha turma and Atualizar controls. Visible labels and interactive states remain in HTML.

The compact Ranking card on the Home page intentionally uses no decorative image. It presents a lightweight HTML preview and links to the complete gallery.
